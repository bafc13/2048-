# 2048 Game — C++ / Qt

2048 game on C++14, Qt 5.10, Qt Widgets. Includes board 4x4, max score counter, movement animations, game restart, undoing a move.
Linux and Windows compatible.

To try:
download code and compile via mingw/msvc, using qmake/cmake.
